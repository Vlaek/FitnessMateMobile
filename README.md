# FitnessMate Mobile

Полностью офлайн-приложение для программ и истории силовых тренировок. Данные хранятся в SQLite только на устройстве; аккаунт и сервер не нужны.

## Возможности

- программы тренировок, встроенные и пользовательские упражнения;
- активная тренировка с автосохранением и восстановлением черновика;
- опциональный таймер отдыха на Android с остановкой из системного уведомления;
- история, редактирование, удаление и системное «Поделиться»;
- недельный объём, динамика упражнений и личные рекорды;
- единый JSON-бэкап программ и/или истории, импорт с объединением или заменой;
- русский и английский, кг и фунты, системная/светлая/тёмная тема;
- safe area для строки состояния, вырезов экрана и нижней панели управления.

## Запуск

```bash
npm install
npm start
```

Затем откройте проект через Expo Go либо development build на Android/iOS.

Системные уведомления таймера отдыха на Android проверяются в development или production build; в Expo Go эта возможность недоступна.

## Проверка

```bash
npm run check
npx expo-doctor
```
