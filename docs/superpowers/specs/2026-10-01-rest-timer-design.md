# Таймер отдыха — дизайн

## Цель

Добавить на Android опциональный таймер отдыха, который автоматически запускается после завершения подхода и управляется через системные уведомления. По умолчанию функция выключена, длительность отдыха — 3 минуты.

## Настройки

В экран настроек добавляется секция «Таймер отдыха»:

- выключатель функции;
- отображение выбранной длительности;
- кнопки уменьшения и увеличения длительности с шагом 30 секунд;
- допустимый диапазон — от 30 секунд до 10 минут включительно;
- значение по умолчанию — 3 минуты;
- функция по умолчанию выключена.

Настройки сохраняются в существующем Zustand-хранилище предпочтений. Сброс данных возвращает выключенное состояние и длительность 3 минуты.

При попытке включить функцию на Android приложение запрашивает разрешение на уведомления. Настройка включается только при полученном разрешении; при отказе остаётся выключенной. На iOS и web таймер не запускается.

## Поведение во время тренировки

Таймер запускается только при переходе подхода из невыполненного состояния в выполненное. Снятие отметки не запускает и не останавливает таймер.

Если пользователь завершает следующий подход во время действующего отдыха, старый таймер и связанные уведомления отменяются, после чего начинается новый полный интервал.

В интерфейсе приложения обратный отсчёт не отображается.

## Android-уведомления

После запуска таймера приложение показывает системное уведомление с временем окончания отдыха, например «Отдых до 18:43», и действием «Остановить».

Одновременно планируется уведомление на момент окончания с текстом «Время отдыха закончилось».

Нажатие «Остановить» отменяет текущий таймер, удаляет его активное уведомление и отменяет запланированное уведомление об окончании. Обработка действия должна работать и когда приложение не находится на переднем плане.

Реализация использует `expo-notifications` и, если требуется для фоновой обработки действия, `expo-task-manager`. Для Android создаётся отдельный канал уведомлений таймера отдыха. Функция проверяется в development или production build, так как Android-уведомления недоступны в Expo Go.

## Архитектура

Платформенная логика инкапсулируется в отдельном сервисе таймера отдыха. Он отвечает за:

- запрос и проверку разрешения;
- регистрацию категории действий и Android-канала;
- запуск с заданной длительностью;
- отмену предыдущего таймера перед новым запуском;
- остановку из приложения или действия уведомления;
- очистку показанного и запланированного уведомлений.

Экран активной тренировки вызывает сервис только при успешном изменении состояния подхода на выполненное. Экран настроек работает через хранилище предпочтений и не содержит деталей API уведомлений, кроме вызова запроса разрешения при включении.

## Ошибки и ограничения

Ошибка создания или отмены уведомления не должна мешать сохранению отметки подхода. Ошибка запроса разрешения оставляет настройку выключенной. Границы длительности дополнительно обеспечиваются на уровне состояния, чтобы сохранённое значение всегда оставалось в диапазоне 30–600 секунд.

## Тестирование

Автоматические тесты покрывают:

- выключенное состояние и 180 секунд по умолчанию;
- сохранение настройки и ограничение длительности диапазоном 30–600 секунд;
- включение только после выданного разрешения;
- запуск таймера при завершении подхода;
- отсутствие запуска при снятии отметки;
- отмену предыдущего таймера при перезапуске;
- остановку через действие уведомления;
- отсутствие платформенных вызовов вне Android;
- русские и английские подписи новой секции и уведомлений.

Перед завершением выполняются целевые тесты, полный набор тестов, проверка типов, линтер и форматирование.
