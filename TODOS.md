# FitnessMate Mobile — плановые задачи

## Высокий приоритет: умная активная тренировка

- [ ] Добавить таймер отдыха после завершения подхода.
  - Быстрые действия: пауза, сброс и добавление 30 секунд.
  - Вибрация и локальное уведомление при завершении таймера, в том числе когда приложение свёрнуто.
  - Настройка длительности отдыха по умолчанию.
- [ ] Показывать результаты предыдущей тренировки рядом с каждым подходом упражнения.
- [ ] Добавить подсказки прогрессии веса или повторений на основе предыдущих результатов.
- [ ] Добавить оценку сложности подхода через RPE или RIR.
- [ ] Добавить заметки к упражнению и всей тренировке.
- [ ] Добавить запуск новой тренировки на основе выбранной завершённой тренировки.

## Прогресс и аналитика

- [ ] Заменить текстовый список динамики полноценными графиками.
- [ ] Добавить графики веса, тренировочного объёма и расчётного одноповторного максимума.
- [ ] Добавить выбор упражнения и периода для просмотра прогресса.
- [ ] Добавить календарь тренировок.
- [ ] Показывать регулярность тренировок и частоту нагрузки по группам мышц.

## Структура тренировок

- [ ] Добавить типы подходов: разминочный, рабочий, дроп-сет и до отказа.
- [ ] Исключать разминочные подходы из рабочих рекордов и при необходимости из аналитики объёма.
- [ ] Добавить объединение упражнений в суперсеты.
- [ ] Поддержать общий цикл выполнения и таймер отдыха для суперсета.

## История тренировок

- [ ] Добавить поиск по названию тренировки и упражнениям.
- [ ] Добавить фильтры по упражнению и диапазону дат.
- [ ] Добавить редактирование завершённой тренировки.
- [ ] Добавить действие «Повторить тренировку» в карточку и экран деталей.

## Сохранность данных

- [ ] Добавить ненавязчивое напоминание о создании резервной копии.
- [ ] Исследовать опциональную синхронизацию между устройствами с сохранением полноценного офлайн-режима.

## Рекомендуемый следующий релиз

Собрать единый релиз «Умная активная тренировка»:

1. Таймер отдыха.
2. Результаты предыдущей тренировки.
3. RPE или RIR и заметки.
4. Повтор завершённой тренировки.
5. Простые подсказки прогрессии.
